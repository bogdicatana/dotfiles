# My Linux setup

## Description
This is my setup for Arch Linux.

## Featuring:
- [sway](https://github.com/swaywm/sway) a tiling Wayland compositor
- [waybar](https://github.com/Alexays/Waybar) (design inspired by [Pipshag](https://github.com/Pipshag/dotfiles_kitties/tree/main/.config/waybar)'s configuration)
- [dunst](https://github.com/dunst-project/dunst) for the notification daemon
- [fish](https://github.com/fish-shell/fish-shell) for my shell, using [starship](https://starship.rs/) for the customized prompt
- [kitty](https://github.com/kovidgoyal/kitty) for the terminal
- [catppuccin](https://catppuccin.com/) for the color scheme
- [neovim](https://neovim.io/) as a code editor, though I do use [zed](https://zed.dev/) as well
- [rofi](https://github.com/davatorium/rofi) for my app launcher and other scripts
